洋芋片的曲面幾何

用參數曲面、法向量、切平面與曲率，描述一片疊得整整齊齊的洋芋片

一、製作動機

吃洋芋片時我發現，這種洋芋片不是平的：一個方向向上彎，垂直的另一個方向卻向下彎，像一個馬鞍。我好奇這個形狀為什麼能成立，也想知道它能不能用課堂上的曲面幾何描述。

這種形狀有實際用途。向兩個相反方向彎曲的薄片比平板更硬、不容易折斷，而且每一片的形狀完全相同，可以整齊地疊進筒子裡。這個作業用簡化的雙曲拋物面（馬鞍面）建立洋芋片模型，並用互動方式觀察它在各點的幾何性質。真實洋芋片的形狀當然更複雜，這裡只做合理的近似。

四、幾何解釋

參數曲面

曲面可以想成把一張平面的「參數紙」(u, v) 彎進三維空間：每個 (u, v) 對應空間中一個點 r(u,v)。本作業取 r(u,v) = (u, v, kx·u² − ky·v²)，也就是把 (u,v) 平面上的點抬高到 z 高度。kx 控制沿 x 方向向上彎的程度，ky 控制沿 y 方向向下彎的程度。

法向量

在曲面上沿 u、v 方向各走一小步，得到兩個切向量 r_u 與 r_v。它們的外積 r_u × r_v 垂直於曲面，標準化後就是單位法向量 n。這裡 r_u = (1,0,2kx·u)，r_v = (0,1,−2ky·v)，所以 n = (−2kx·u, 2ky·v, 1)/√(1+4kx²u²+4ky²v²)。法向量表示曲面在該點「朝向哪裡」。

切平面

切平面是通過該點、並由 r_u 與 r_v 張成的平面，也是用平面對曲面做的最佳一階近似。把曲面放得很大看一個點，它會越來越像這個切平面。切平面與法向量互相垂直，所以選一個就決定了另一個。

曲率

曲率描述曲面離開切平面的速度。在一點取各個方向的切線，彎曲程度最大與最小的兩個值稱為主曲率 k₁、k₂。高斯曲率 K = k₁·k₂。洋芋片的 K 是負的，因為兩個主曲率一正一負，一個方向向上彎、另一個向下彎，這種點叫鞍點（雙曲點）。K 為正的點像碗或球面，K 為 0 的點像圓柱面或平面。
